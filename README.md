# Community Issue Reporting System

## Summary
This project aims to address uncollected garbage and road hazards in local neighborhoods. It allows residents to easily submit reports with location tags and photos to local officials.

## Current stack
Flutter Web / Dart; planned REST API and PostgreSQL.

## Run locally
flutter pub get
flutter run -d chrome
